## API shapes
- GET /site/address (owner) -> {slug|null, suggested_slug, url|null, address|null, published, root_domain, hide_branding}
- GET /site/slug/check?slug= (owner) -> {slug, ok, reason, message, suggestion, url} (live validation)
- POST /site/publish {slug?} (owner) -> {slug, url, address, published: true, published_at}; 422 error.code
  slug_invalid|slug_reserved|slug_taken (also on a unique-index race); 409 not_ready without a build or review stage.
- PATCH /site/branding {hide_branding} (owner; 403 for the demo subject on a real hotel) -> {hide_branding}.
  hide_branding was removed from PATCH /site. No plan is stored in the DB, so "Pro" is a UI label only.
- GET /public/site/{slug} -> site payload from the stored slug (moved slugs answer with redirect_to); SiteContent
  only once published, else the labelled sample for the sample hotel; rooms = owner-typed price_paise (as
  nightly_rate, rooms with price 0 dropped); photos [{id, url "/api/public/site/<slug>/photos/<id>?v=<sha8>", width,
  height, caption_en, caption_hi}]; hide_branding; booking_url ("/link", or "<WEB_ORIGIN>/link" with a root domain).
  404 "This hotel site isn't live yet" for unknown/unpublished.
- GET /public/site/{slug}/resolve -> {state: live|moved|none, slug}
- GET /public/site/{slug}/photos/{id} -> image/jpeg, Cache-Control public, max-age=86400, immutable, ETag "<sha256>",
  304 on If-None-Match; published sites only (own bucket). No public route calls Claude (tested with a booby trap).
- Slugs: ^[a-z0-9]+(-[a-z0-9]+)*$, 3-40, reserved = www app api admin mail docs status + every app route name.
  Rename keeps previous_slug + slug_changed_at: old slug redirects and stays held for 30 days, then frees up.

## Routing (proxy.ts, SITE_ROOT_DOMAIN read per request; hotel host = exactly <valid slug>.<root> or <slug>.localhost)
| Host | Path | Result |
|---|---|---|
| hotel | / | resolve: live -> rewrite /h/<slug>; moved -> 308 to <new>.<root>; none -> 404 not-live HTML (noindex) |
| hotel | /api/public/site/<own slug>[/...] GET/HEAD, /_next/* | pass |
| hotel | anything else (/login, /home, /h/x, /api/site, writes) | 404 |
| app | /h/<slug> | live pass; moved 308 /h/<new>; none or bad shape 404 not-live |
| app | /hotel/<slug> | 308 /h/<slug> (page fallback too) |
| app | owner paths | session guard as before |
Owner cookies: no Domain attribute anywhere (grep plus a node test), so hotel hosts never receive them.
