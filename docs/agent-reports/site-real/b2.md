## How each step calls the API (shapes from routers/site_build.py)
- Load: GET site/build (BuildState).
- Photos: XHR POST /api/site/photos, multipart field "photo", one file per request, with real progress.
  The picker accepts image/jpeg,image/png,image/webp,image/heic,.heic. It checks type and the 10 MB limit before upload.
  Errors show the API's error.message. Only 8 photos fit. Thumbnails use photo.url and a lint-disabled <img>.
  Order: PATCH site/photos/order {ids}. It updates at once, rolls back on error, and keeps focus on the moved
  photo's button. Delete: DELETE site/photos/{id}.
- Describe: textarea of up to 2000 letters. PATCH site/build {owner_description}. MicButton uses SpeechRecognition or
  webkitSpeechRecognition, with hi-IN or en-IN, continuous, and interim text in aria-live. It appends to the box.
  Where the browser has no speech recognition, a typed-fallback note shows instead. No audio reaches Seedha.
  The note is honest that Chrome may use Google's speech service. next.config already allows microphone=(self).
- Rooms: 1 to 10 rows. Rupees are converted to integer paise in lib/siteBuild.rupeesToPaise
  (max ₹1,00,000 = 10,000,000 paise, the API's cap). Duplicate names are refused.
  PATCH site/build {rooms:[{name, price_paise}]}; blurbs are left out so the API keeps them by name.
  The ₹ display uses inr() only at the edge.
- Generate: POST site/build/generate. An indeterminate bar shows while it runs. GenerateNote handles the statuses:
  generated, sample (Sample tag plus the API message), limit_reached and offline (the API message).
  fallback_fields become plain labels ("Some lines were written from your own words: Description (Hindi), Photo
  captions"). A second run from this step uses the same confirm. When the key is set and generations_today >= daily_limit,
  the button is disabled. Then PATCH /site {stage:"review"}.
- Review edits use PATCH site/build: content.{description,google_description}_{en,hi},
  why_book_direct_{en,hi} (3 points each, 1 to 120 letters), rooms with blurb_en/blurb_hi (up to 300 letters; name and price
  are sent unchanged), and captions [{photo_id, caption_en, caption_hi}] (8 words or fewer, 120 letters or fewer).
  After each save, GET /site is reloaded for the preview.
- AiUsage: GET site/gen/usage. Shows month input and output tokens (input includes cache tokens), runs, the cap
  and today's count, and the last 5 runs. Loading, error and empty states are included.
