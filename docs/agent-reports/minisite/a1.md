API contract
- `details.rooms[]`: `name, size_sqft|null, beds_en, beds_hi, max_guests|null, features_en[<=2], features_hi[<=2], photo_id|null`.
- Public `GET /public/site/{slug}`: `from_price_paise: int|null`, `ratings: {count, average: float|null, comments: [{stars, comment, month: "YYYY-MM"}]}`. Average and comments only when count >= 3; hidden comments never shown, their stars still count; at most 12 comments. Hosted (production) sample hotel always shows `{count: 0}`.
- `GET /public/rate/{token}` -> `{hotel, slug, state: "open"|"used"|"invalid"}` (invalid: empty hotel and slug).
- `POST /public/rate/{token}` `{stars 1..5, comment? <=200}` -> 204, then 409 `already_rated`; 404 `no_such_rating_link`; extra keys 422.
- Owner `GET /site/ratings` -> `[{id, stars, comment, hidden, created_at (when rated), source: "link"|"desk"}]`; `PATCH /site/ratings/{id}` `{hidden}` only (stars -> 422).
- `rating_url` = `<web_origin>/rate/<token>` (web_origin is PUBLIC_BASE_URL or WEB_ORIGIN). Owner `GET /site` `card_urls: {wallet, room, desk}`.
- Reset demo data deletes all site_rating rows (zero ratings).
